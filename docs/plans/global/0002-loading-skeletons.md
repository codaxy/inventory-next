# 0002 — Loading skeletons

What a screen shows while its data is on the way: its own outline, not "Loading…" and not an empty
form. The outline is the screen's real layout with bars for the text, so the data arrives without
anything moving.

1. ~~**Skeleton vocabulary, the dashboard and the lists.**~~ The bars as shared styles; the dashboard's
   card and list outlined; the lists' first load as rows shaped like theirs. First because the
   dashboard is where the wait shows most, and the lists share its helper.
2. **Record pages.** A bar in place of each value until the record arrives. Apart because it touches
   every editor, and the pattern is judged on step 1 first.
